# MCW business concept

## Audience

Any Android user seeking user-invoked AI screen observation and noninteractive visual guidance, including learning, troubleshooting and games.

## Value proposition

AI remains in a selected provider app; the MCW companion mediates permission-scoped screen observations and annotations. Opening a provider app does not automatically establish an MCP connection. Each supported provider needs a verified adapter and explicit user authorization.

## Key risks to validate

Provider MCP support on mobile; Android overlay and MediaProjection constraints; real-time session security and isolation; privacy and consent; free-tier infrastructure economics; app distribution policies; accessibility; subscription demand.

## Success criteria to define before experiments

Successful user-invoked pairing, revocation, correct tenant isolation, no unapproved observation, reliable drawing, understandable UX, acceptable cost per active session. Metrics and thresholds are not yet approved.
