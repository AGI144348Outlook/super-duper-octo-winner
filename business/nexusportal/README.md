# NexusPortal — AI screen companion

**Contract-000 business candidate. Status: proposed, not launched.** NexusPortal is the product and platform name. **MCW** is a technical connection capability, **not** the app name.

## Product

NexusPortal is a public, multi-user Android AI screen companion. Users explicitly invoke a connection with the floating `%` control, select a supported AI, and grant observation and visual annotation permissions separately. The transparent layer provides non-interactive, touch-through visual guidance. Pause, stop, and revoke remain user-controlled. No direct device control in v1.

## Product naming

- **NexusPortal:** consumer app and platform
- **NexusPortal Connect:** user-authorized AI connection experience
- **NexusPortal Layer:** transparent overlay renderer
- **NexusPortal Studio:** future optional features
- **MCW/MCP:** technical protocols/capabilities, not the product name

## Business proposal

The essential product, consent, privacy, accessibility and stop/revoke controls remain free. The newest two *optional* premium features can be premium; releasing a third graduates the oldest to free. Pricing, provider interoperability, costs and demand remain unverified.

## Existing assets and deployment boundaries

An existing Vercel project named `nexusportals-diagram` has been identified. It has a READY deployment but is not verified as a live public NexusPortal product website; its source and suitability require inspection. Do not overwrite or repurpose it without review. Cloudflare, Render and Neon are candidate services, not deployed NexusPortal dependencies. Actual Android renderer and gateway source belong in a separate product engineering repository once selected.
